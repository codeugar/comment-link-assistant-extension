# 外链库、计划与推广网站统一创建流程 Spec

状态：Confirmed，可进入开发
基线：Comment Link Assistant v0.4.0

## 1. 背景

当前新建计划只能通过粘贴文本或导入文件添加目标博客 URL。外链库已经保存了可执行的博客域名，但创建计划时不能直接复用；外链库页面也不能选中域名后发起计划。

推广网站目前主要在侧边栏设置中维护。运营看板没有直接的新建入口，新建计划时如果缺少所需推广网站，也必须离开当前流程后再配置。

## 2. 目标

1. 用户可在新建计划弹窗中从外链库选择域名，直接导入目标 URL 文本框，无需复制粘贴。
2. 用户可在外链库页面跨筛选、跨分页选择域名，然后打开同一个新建计划弹窗。
3. 用户可从运营看板直接新建推广网站。
4. 用户可在任意新建计划场景中通过推广网站下拉框新建推广网站，新建后继续原计划，不丢失已填内容。
5. 所有入口复用同一个 `NewPlanDialog` 和同一个推广网站创建浮层，不复制数据模型或表单实现。

## 3. 非目标

- 不从计划执行结果自动创建推广网站。
- 不把计划中的目标 URL 自动写回外链库。
- 不在本次需求中增加计划自动运行、定时运行或自动选择目标。
- 不改变外链库的域名级数据模型，也不把路径保存到外链库。
- 不改变全局模型供应商和 API Key 的配置方式。

## 4. 统一对象与数据规则

### 4.1 目标博客

- 外链库记录仍以规范化域名为唯一站点标识，例如 `www.example.com/post` 归一为 `example.com`。
- 导入新建计划时转换为可执行 URL：`https://example.com`。
- 和计划文本框已有内容合并时，沿用现有计划解析器的 URL 规范化与去重规则。
- 从外链库导入只追加，不删除或覆盖用户已经输入的目标。
- 外链库条目被编辑后，已选状态按条目 `id` 保持；打开计划时使用该条目的最新域名。
- 外链库条目被删除时，同时从选择集合移除。

### 4.2 推广网站

复用现有 `SiteProfile`：

- `label`：推广网站名称，必填。
- `websiteUrl`：推广网站 URL，必填；允许用户省略 `http://`、`https://` 和 `www.`，保存时规范化为 HTTPS URL。
- `displayName`：评论显示名称，选填。
- `email`：评论邮箱，选填；填写时必须是合法邮箱。
- `linkMode`：链接写入方式，必填；默认 `a-tag-newline`。
- `id`：创建时生成，不允许用户编辑。

约束：

- 继续遵守最多 20 个推广网站的现有限制。
- 规范化后与现有推广网站 URL 相同的记录不可重复创建。
- 新建成功后写入 `ExtensionSettings.sites`，并将 `activeSiteId` 更新为新网站。
- 模型供应商与 API Key 不出现在该浮层中，继续使用全局设置。

## 5. 用户流程

### 5.1 新建计划弹窗：从外链库导入

入口：目标博客 URL 文本框附近的“从外链库选择”按钮。

1. 用户打开现有 `NewPlanDialog`。
2. 用户可先填写计划名称、推广网站、批次大小或目标文本。
3. 点击“从外链库选择”后，在计划弹窗上方打开选择浮层。
4. 选择浮层支持域名搜索、逐项勾选、本页全选/取消、选中计数。
5. 点击“导入到计划”后，将选中域名转换为 HTTPS URL，追加到现有目标文本并去重。
6. 关闭选择浮层不修改目标文本；重新打开选择浮层时从空选择开始，定位为一次追加操作。
7. 计划弹窗中此前填写的所有字段保持不变。

状态要求：

- 外链库为空时显示空状态，并提供前往外链库页面的入口。
- 外链库正在加载时禁用确认按钮。
- 未选择域名时“导入到计划”禁用。
- 导入成功后关闭选择浮层，但保持新建计划弹窗打开。

### 5.2 外链库页面：选择域名并新建计划

1. 每一行增加选择框。
2. 页面操作区显示“已选择 N 个”和“新建计划”按钮。
3. 支持对当前可见页全选或取消当前页；不会影响其他页已选择项。
4. 搜索、属性筛选、分页、刷新不会清空选择。
5. 编辑条目、导入文件不会自动选中新条目。
6. 未选择任何条目时“新建计划”按钮禁用。
7. 点击“新建计划”后打开全局唯一的 `NewPlanDialog`，目标文本预填为所选域名对应的 HTTPS URL。
8. 用户可继续编辑目标、计划名称、推广网站和批次大小。

选择清理规则：

- 取消或关闭计划弹窗：保留外链库页面选择，方便再次打开。
- 计划创建成功：清空外链库页面选择。
- 删除已选条目：立即从选择中移除。
- 离开外链库路由后再返回：本次页面会话内保留；浏览器刷新后不要求持久化。

### 5.3 运营看板：新建推广网站

入口：运营看板页面头部操作区的“新建推广网站”按钮。

1. 点击后打开统一的 `CreatePromotingSiteDialog` 浮层。
2. 保存成功后关闭浮层、刷新 `settings.sites`，显示成功提示。
3. 紧接着打开统一的 `NewPlanDialog`，并自动选中刚创建的推广网站。

### 5.4 新建计划：在推广网站下拉框中新建

适用于从计划管理和外链库页面打开的同一个 `NewPlanDialog`。

1. 推广网站下拉框最后增加固定选项“＋ 新建推广网站…”。
2. 选择该选项时，不改变当前已选推广网站；在计划弹窗上方打开统一推广网站创建浮层。
3. 新建成功后自动选择新推广网站，并返回原计划弹窗。
4. 计划名称、目标 URL、文件导入结果和批次大小全部保持。
5. 取消推广网站创建时，返回原计划弹窗并保留原推广网站选择。

## 6. 弹窗与状态架构

顶层 `App` 维护：

- `newPlanOpen`
- `newPlanInitialTargetText`
- `newPlanSource`：`dashboard | plans | outbound-library`
- 外链库页面选中条目 ID 集合
- `createPromotingSiteOpen`
- 推广网站创建成功回调目标：`dashboard | new-plan`

原则：

- 页面组件只发出意图，例如 `onNewPlan(selectedEntries)`、`onCreatePromotingSite()`。
- `NewPlanDialog` 只存在一个实例，由顶层控制。
- `CreatePromotingSiteDialog` 只存在一个实例，可覆盖在计划弹窗上方。
- 打开嵌套浮层时不卸载 `NewPlanDialog`，避免本地表单状态丢失。
- 新建计划成功事件需要携带来源，以决定是否清空外链库选择。

## 7. 错误与边界

- 外链库选择中的条目在确认前被删除：忽略已不存在的 ID，并更新选中计数。
- 外链库条目域名无效：不应进入持久化列表；若旧数据异常则跳过并提示。
- 推广网站名称为空、URL 无效、邮箱无效或达到 20 条限制：保留浮层输入并显示字段级错误。
- 推广网站重复：保留输入，提示“该推广网站已存在”，不创建重复项。
- 保存推广网站失败：保持两个弹窗状态，允许重试。
- 计划创建失败：保持外链库选择和计划表单内容。
- Preview 模式：两类新建流程均可在内存中演示，不调用不可用的后台接口。

## 8. 文案与无障碍

新增文案必须同时提供简体中文和英文：

- 从外链库选择 / Select from library
- 导入到计划 / Add to plan
- 已选择 N 个 / N selected
- 新建计划 / Create plan
- 新建推广网站 / Add promoting site
- ＋ 新建推广网站… / + Add promoting site…

要求：

- 选择框具有包含域名的可访问名称。
- 本页全选使用原生 checkbox 的 indeterminate 状态。
- 两层弹窗均有 `aria-modal`、标题关联和 Escape 行为。
- Escape 只关闭最上层浮层，不同时关闭计划弹窗。
- 保存中禁用重复提交，使用 `aria-busy` 或等价状态。
- 成功、失败信息继续使用现有 Toast；字段校验信息与字段关联。

## 9. 验收标准

### 外链库到计划

- 可在计划弹窗中搜索并选择外链库条目，确认后追加、规范化并去重。
- 可在外链库页面跨两页选择条目，打开同一个计划弹窗并看到全部预填目标。
- 筛选后本页全选只影响当前页。
- 取消计划不清空外链库选择；创建成功后清空。
- 删除已选条目后计数和计划预填均不包含该条目。

### 推广网站

- 运营看板按钮可打开推广网站创建浮层并成功保存，随后自动打开新建计划且选中新网站。
- 计划弹窗下拉框可打开同一浮层；成功后自动选中新网站。
- 取消、校验失败和保存失败均不丢失计划表单。
- 裸域名 `example.com` 保存为规范化 HTTPS 推广网站 URL。
- 重复网站与第 21 个网站会被阻止。

### 回归与质量

- 计划文本/CSV/TXT/Excel 原导入能力保持。
- 外链库 CRUD、批量导入、搜索、筛选、分页保持。
- Settings 侧边栏现有推广网站编辑保持。
- 中英文切换后所有新增文案正确。
- TypeScript、Biome lint、完整 Vitest 和生产构建通过。

## 10. 已确认产品决策

已确认：

1. 从计划弹窗打开外链库选择器时，每次从空选择开始；用户手动勾选所需外链库域名，确认后只追加。
2. 推广网站名称 `label` 必填。
3. 从运营看板新建推广网站成功后，立即打开新建计划并自动选中新网站。
